# Lab Activity 5: Reactive Android App

This is a simple Android application built with **Jetpack Compose** that demonstrates basic state management and reactivity.

## Features

- **Personalized Greeting**: Greets the user based on the name entered in the text field.
- **Reactive Counter**: A simple counter that can be incremented, decremented, and reset.
- **State Persistence**: Uses `rememberSaveable` to ensure the counter and name survive configuration changes (like screen rotation).

## Tech Stack

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Modern toolkit for building native UI.
- **Material 3**: Design system for the UI components.
- **Gradle (Kotlin DSL)**: Build automation tool.

## How to Run

1. Clone this repository.
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Sync the project with Gradle files.
4. Run the `:app` module on an emulator or a physical device (API level 24+).
